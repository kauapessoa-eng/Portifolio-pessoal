# Portfólio — Kauã Dórea

Olá! Meu nome é Kauã Dórea e sou estudante de Engenharia de Software. Criei este portfólio para apresentar um pouco sobre mim, meus conhecimentos e alguns projetos que desenvolvi durante meus estudos.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## O que você encontra no portfólio?

- Uma apresentação sobre mim;
- Meus conhecimentos em tecnologia;
- Projetos desenvolvidos;
- Formulário para contato.

## Como executar

Para acessar o portfólio, basta abrir o link publicado:

[Visualizar meu portfólio](https://kauapessoa-eng.github.io/Portifolio-pessoal/)

Para executar no computador:
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Organização dos arquivos

- `index.html`: estrutura e conteúdo da página.
- `style.css`: aparência e organização visual.
- `script.js`: filtros dos projetos e funcionamento do formulário.

## Documentação da atividade

Os documentos complementares desta atividade estão na pasta `documentacao`, incluindo o diagnóstico, as evidências, a matriz de testes, a revisão do colega e a explicação da refatoração e do contato.
