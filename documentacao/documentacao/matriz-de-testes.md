# Matriz de testes

Foram considerados os principais recursos do portfólio para verificar seu funcionamento.

| Teste | Resultado esperado | Resultado |
|---|---|---|
| Abrir o portfólio | A página deve carregar corretamente. | Aprovado |
| Navegar pelo menu | Os links devem levar às seções correspondentes. | Aprovado |
| Filtrar projetos | Devem aparecer apenas os projetos da categoria escolhida. | Funcionalidade implementada |
| Acessar em tela menor | O conteúdo deve se adaptar ao tamanho da tela. | Responsividade implementada |
| Enviar formulário vazio | O sistema deve identificar os campos obrigatórios não preenchidos. | Validação implementada |
| Selecionar a opção "Outro" | Deve aparecer um campo adicional para informar o assunto. | Funcionalidade implementada |
| Enviar formulário preenchido | O sistema deve tentar enviar a mensagem e apresentar um retorno ao usuário. | Envio implementado; recebimento do e-mail depende da confirmação do FormSubmit |

## Conclusão

Os testes e a análise do código mostram que o portfólio possui recursos de navegação, filtros, adaptação para telas menores e validação do formulário. O recebimento de mensagens por e-mail depende da confirmação do serviço de envio.
