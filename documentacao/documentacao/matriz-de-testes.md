# Matriz de testes

Realizei testes para verificar se as principais funções do portfólio estavam funcionando corretamente.

| Teste | Resultado esperado | Resultado |
|---|---|---|
| Abrir o portfólio | A página deve carregar corretamente. | A preencher |
| Navegar pelo menu | Os links devem levar às seções correspondentes. | A preencher |
| Filtrar projetos | Devem aparecer os projetos da categoria escolhida. | A preencher |
| Acessar pelo celular | O conteúdo deve se adaptar à tela. | A preencher |
| Enviar formulário vazio | O sistema deve indicar os campos obrigatórios. | A preencher |
| Selecionar "Outro" | Deve aparecer o campo adicional de assunto. | A preencher |
| Enviar formulário preenchido | A mensagem deve ser encaminhada e o usuário deve receber um retorno. | A preencher |
