# Diagnóstico do portfólio

Durante a análise do meu portfólio, identifiquei cinco pontos que precisavam de melhorias:

1. **Organização do código:** separar o HTML, CSS e JavaScript em arquivos diferentes para facilitar a leitura e as alterações.

2. **Responsividade:** adaptar o site para funcionar melhor em telas menores, como celulares.

3. **Botões de filtro:** permitir que os botões passem para outra linha quando não houver espaço suficiente na tela.

4. **Validação do formulário:** verificar se os campos obrigatórios foram preenchidos antes do envio.

5. **Envio do formulário:** apresentar mensagens informando se o envio foi concluído ou se ocorreu algum erro, além de evitar envios repetidos.

Essas melhorias contribuíram para deixar o portfólio mais organizado, fácil de utilizar e com melhor funcionamento.
